# Student Management System

Version: 2.0 - Team Development

## Giới thiệu
Dự án thực hành quản lý mã nguồn bằng Git và GitHub
trong học phần DevOps.

## Chức năng
- Quản lý danh sách sinh viên.
- Quản lý danh sách môn học.
- Lưu thông tin chi tiết sinh viên.

## Cấu trúc file
- students.txt: Danh sách sinh viên.
- subjects.txt: Danh sách môn học.
- student-info.txt: Thông tin chi tiết sinh viên.
- .gitignore: Quy định các file không đưa vào Git.

## Xem dữ liệu
Dùng các lệnh:
- cat students.txt
- cat subjects.txt
- cat student-info.txt

## Nội dung thực hành
- Add, commit và xem lịch sử.
- Tạo nhánh và merge.
- Push, pull và clone.
- Tạo và giải quyết merge conflict.
- Tạo Pull Request và kiểm tra thay đổi.
- Khôi phục file bằng restore và hoàn tác commit bằng revert.
